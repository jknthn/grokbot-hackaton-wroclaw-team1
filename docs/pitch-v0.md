# Pitch v0 (90s) — locked loop v1

1. **Hook:** Multiplayer AI isn’t one chatbot — it’s humans and bots who look the same in one town hall, and nobody knows who is who.
2. **Kernel:** Humans and bots are the same `Player` type on a shared seat table (show the circle).
3. **Talk:** Everyone writes blind — one short line, then the room reveals them all at once. No live scroll, so bots cannot copy the last human.
4. **Pressure:** City **crisis** uses the same simultaneous reveal (fail and a human dies) → **vote** (kick and reveal) → night **strike** (solo bots spend one kill token). Text only.
5. **Multiagent claim:** bots know they are bots, work **alone** (no private bot chat), and must blend while thinning humans — conflicting goals on shared public state.
6. **Close:** Can the town vote out the bots before the bots remove the people?
